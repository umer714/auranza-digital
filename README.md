# AURANZA — Premium Digital Growth Studio

Responsive static marketing website for AURANZA.

## Files
- `index.html` — main responsive website and contact form that opens the visitor's email app.
- `privacy.html` — starter privacy notice; review and adapt before launch.

## Deploy on Vercel
Import this repository into Vercel and use the repository root as the Root Directory. This static HTML site needs no framework preset, build command, or output directory.

## Before public launch
- Confirm `auranza.digital@gmail.com` is an inbox you own and monitor; update it in both HTML files if needed.
- Review the privacy notice against actual business practices and applicable laws.
- Portfolio cards are illustrative concepts, not claims of completed client work.
- Add real business details and verified social profiles only when available.
